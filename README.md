# XNova 
XNOVA — Solana Token
Overview

XNOVA is a Solana-based community token designed for a fast, low-cost, and accessible Web3 ecosystem.

The project focuses on building a strong community around the XNOVA brand while exploring future utilities, decentralized applications, rewards, and ecosystem integrations.
